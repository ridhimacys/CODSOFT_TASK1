# CodSoft Task 1 - Network Packet Analyzer

## Overview

This project was completed as part of my CodSoft Cyber Security Internship.

The Network Packet Analyzer is a Python-based tool that captures and analyzes network packets using the Scapy library.

## Features

- Captures network packets
- Displays source IP address
- Displays destination IP address
- Identifies common protocols
- Displays packet length
- Provides formatted packet information

## Technologies Used

- Python
- Scapy
